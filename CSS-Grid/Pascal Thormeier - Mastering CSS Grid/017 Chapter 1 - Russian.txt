Расположение элементов сетки

До сих пор CSS Grid сам заботился о расположении элементов за нас — в нашем примере он автоматически создал четыре строки, потому что было четыре элемента, равномерно распределил их и разместил в том же порядке, в котором они шли в DOM.

Однако часто мы этого не хотим, особенно когда речь идёт об адаптивных макетах. Например, на мобильном кнопки соцсетей могут перемещаться вниз страницы и становиться «прилипающими» элементами, тогда как на десктопе они должны оставаться на одном месте, например в боковой панели.

Чтобы иметь возможность перемещать элементы, сначала нужно явно указать количество строк и столбцов грида. Мы делаем это с помощью правил `grid-template-rows` и `grid-template-columns`, которые задаются на элементе-контейнере и заранее создают для нас структуру грида. Мы задаём количество столбцов и строк грида, указывая их размеры через пробел. Размер может отличаться от строки к строке и от столбца к столбцу.

Общее количество грид-ячеек может быть больше, чем общее количество элементов, которые мы хотим расположить. Например, мы можем определить грид из трёх строк и трёх столбцов и разместить в нём только пять элементов — случай, распространённый в галереях или новостных сайтах. Оставшиеся грид-ячейки остаются пустыми.

Пока что давайте поработаем с 1fr. fr — это единица измерения, которая была введена в CSS вместе с CSS Grid и работает исключительно с гридами. 1fr по сути означает: «Возьми одну единицу свободного пространства для этого грид-элемента». Единицу fr мы обсудим позже в этой главе. Итак, если мы используем её для строк грида, это означает взять одну единицу свободного пространства для этой строки грида. То же самое относится и к столбцам.

Давайте изменим наш пример на грид 2×3 из равномерно распределённых грид-элементов, применив следующий CSS-код к классу container:

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: 1fr 1fr 1fr;
}

Как видим, мы использовали 1fr дважды в grid-template-columns, что дало два одинаковых по размеру столбца, и трижды в grid-template-rows, что дало три одинаковых по размеру строки.
