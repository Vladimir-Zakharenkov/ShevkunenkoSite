Мы видим четыре элемента, которые хотим выровнять в гриде, а именно:

- **Шапка (header)**, которая может содержать логотип или навигацию
- **Элемент**, который будет содержать контент, не относящийся напрямую к основному содержимому страницы
- **Элемент** для собственно основного контента
- **Подвал (footer)**, отображающий такие вещи, как контактные данные, информация о компании, ссылка на FAQ и аналогичные дополнительные элементы управления

Для наглядности мы заранее применим следующий CSS (этот код пока никак не связан с CSS Grid и служит исключительно для иллюстрации):


/* 01_page_layout.html, Micro-resetting */
body {
  padding: 0;
  margin: 0;
}

* {
  box-sizing: border-box;
  font-size: 25px;
}

/* Making things visible on the page */
.container {
  border: 2px solid #555;
  padding: 8px;
  min-height: 100vh;
}

header {
  border: 2px solid #dd0808; /* Dark red */
  background-color: #ff6666; /* Light red */
}

aside {
  border: 2px solid #0ba7c6; /* Dark cyan */
  background-color: #74ddf2; /* Light cyan */
}

main {
  border: 2px solid #6f09e5; /* Dark purple */
  background-color: #b880f7; /* Light purple */
}

footer {
  border: 2px solid #c4be0d; /* Dark yellow */
  background-color: #f7f380; /* Light yellow */
}

Этот CSS-код раскрасит наши контейнеры и позволит отслеживать, какой элемент где находится. При загрузке в браузере это даст четыре цветные полосы вдоль экрана. Именно этого мы и ожидали. В конце концов, в нашей DOM пока нет никакого контента.
