Глава 1

Понимание базовых правил и структур CSS Grid

Добро пожаловать в первую главу этой книги под названием «Mastering CSS Grid». Как следует из названия, эта книга помогает нам стать профессионалами в этой технике вёрстки и изучить все её особенности и детали. На протяжении всей книги мы будем работать над различными задачами с использованием грид-макетов в рамках общего проекта под названием Awesome Analytics.

В первой главе этой книги мы начнём знакомить вас с CSS Grid. Сначала нам нужно установить его базовые CSS-правила, чтобы понять, как работает модель грида. Для этого мы рассмотрим, как устроены сетки и как мы можем визуально их представить. Мы изучим CSS-правила, используемые для создания грид-макетов, как комбинировать их для достижения разных вариантов расположения элементов и как использовать сокращённые правила, чтобы укоротить наш код.

Взгляд на то, как инструменты разработчика Google Chrome и других браузеров на движке Chromium визуализируют гриды, поможет нам понять, как отлаживать и анализировать существующие сетки. В этой главе мы пока не будем работать с нашим общим проектом — сначала мы рассмотрим немного теории.

Итак, в этой главе мы рассмотрим следующие темы:

- Понимание базовых правил, связанных с CSS Grid
- Использование грид-шаблонов
- Поток грида
- Понимание специальных единиц измерения, ключевых слов и функций, связанных с гридами
- Использование сокращённых записей

Технические требования

Для этой главы нам понадобится примерно то же самое, что и для большинства глав, а именно:

- Современный браузер, поддерживающий CSS Grid и предлагающий отладку гридов и набор инструментов для работы с ними
- Интегрированная среда разработки (IDE) или текстовый редактор, такой как WebStorm, VS Code или Vim, с подсветкой синтаксиса HTML и CSS
- Доступ в интернет — это преимущество, но не обязательно

Несколько примеров кода можно найти на GitHub в этом репозитории: https://github.com/PacktPublishing/Mastering-CSS-Grid/tree/main/chapter1.

Все скриншоты и примеры сделаны в браузере на движке Chromium.
