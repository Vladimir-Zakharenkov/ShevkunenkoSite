Что охватывает эта книга

Глава 1. Понимание базовых правил и структур CSS Grid** — охватывает основы: терминологию гридов, создание первых сеток, расположение элементов грида и грид-шаблоны.

Глава 2. Введение в проект: над чем мы будем работать и первые задачи** — представляет сопутствующий проект, над которым мы будем работать на протяжении всей книги.

Глава 3. Построение продвинутых грид-макетов** — знакомит с продвинутыми возможностями CSS Grid, такими как оси строк и столбцов, выравнивание и распределение содержимого грида, а также продвинутые грид-шаблоны.

Глава 4. Понимание и создание адаптивных и гибких грид-макетов** — рассказывает о том, что такое адаптивные и гибкие макеты, какие существуют лучшие практики и как строить такие макеты с помощью CSS Grid.

Глава 5. Реализация макетов с помощью Flexbox и CSS Grid** — исследует различия и сходства между CSS Grid и Flexbox и их конкретные сценарии использования.

Глава 6. Преимущества грид-макетов и когда их не стоит использовать** — обсуждает плюсы и минусы грид-макетов в контексте дизайна и удобства использования, а также знакомит с альтернативными методами вёрстки.

Глава 7. Полифилы для отсутствующих возможностей CSS Grid** — знакомит с PostCSS и JavaScript для реализации недостающих возможностей и лучшего понимания того, как они будут работать после внедрения.

Глава 8. Гриды в реальном мире — как фреймворки реализуют сетки** — рассматривает различные подходы к сеткам в восьми разных CSS-фреймворках, объясняя, как реализовать стандартные сценарии использования.

Глава 9. Краткий справочник и шпаргалка** — даёт сжатый обзор всех возможностей CSS Grid, терминологии и наиболее важных фреймворков, а также предлагает фрагменты кода для стандартных сценариев использования.

Как извлечь максимум из этой книги**

Мы рекомендуем иметь некоторые знания базовых и продвинутых возможностей CSS и JavaScript, таких как пользовательские CSS-свойства или промисы. Также рекомендуется понимать, как работает Flexbox. Предполагается уверенное знание HTML.
