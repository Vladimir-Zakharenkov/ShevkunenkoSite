CSS Grid присваивает целые числа всем грид-линиям, чтобы мы могли использовать их в качестве координат. Эти числа увеличиваются слева направо и сверху вниз, начиная с 1. Когда мы представляем грид как систему координат, её начало находится в левом верхнем углу. Это позволяет нам размещать грид-элементы начиная с левого верхнего и до правого нижнего угла.

Однако CSS Grid предлагает и второе начало отсчёта, которое позволяет размещать элементы с правого нижнего угла к левому верхнему. Для этого он также присваивает отрицательные целые числа тем же самым грид-линиям, начиная с правого нижнего угла со значения -1.
