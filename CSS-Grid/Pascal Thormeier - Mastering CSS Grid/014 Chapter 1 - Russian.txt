.container {
  display: grid; /* Marks this class as a grid container */
}

При перезагрузке мы видим, что CSS Grid равномерно распределил четыре контейнера по вертикали. Поскольку внешний элемент <div> имеет фиксированную высоту, CSS рассчитает высоту каждого элемента и перемасштабирует его, чтобы всё поместилось.
