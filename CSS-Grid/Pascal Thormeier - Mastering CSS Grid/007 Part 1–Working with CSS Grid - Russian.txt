Часть 1. Работа с CSS Grid

В этой части вы научитесь работать с CSS Grid. Вы изучите базовые и продвинутые возможности CSS Grid. Кроме того, начиная со второй главы, вы будете практиковаться на специальном проекте, который будет сопровождать вас на протяжении всей книги — он называется AwesomeAnalytics, это реалистичный пример проекта, активно использующего CSS Grid.
