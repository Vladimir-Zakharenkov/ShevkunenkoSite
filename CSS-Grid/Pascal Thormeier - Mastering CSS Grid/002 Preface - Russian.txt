Однако есть и проблемы. Проблемы с табличной вёрсткой и плавающими элементами были многочисленны. Во-первых, они требовали большого количества шаблонного кода и иногда казались чистой магией. Чтобы правильно выровнять плавающие элементы, мы также должны учитывать все элементы вокруг них.

Во-вторых, таблица — это способ отображения данных, а не инструмент вёрстки. Люди тогда были далеко не так осведомлены о доступности, как сегодня, и нам всё ещё есть куда расти. Когда ранние скринридеры встречали таблицу, они интерпретировали её как таблицу. А в таблицах — данные, а не навигация.

Flexbox решил множество проблем позиционирования. Было много трюков, чтобы выровнять элементы по центру и по вертикали, и по горизонтали. Некоторые из них актуальны и по сей день. Flexbox упростил задачу, и код стал куда более прямолинейным. Смысл `display: flex; justify-content: center;` гораздо более явный, чем у `margin: 0 auto;`.

Но в конечном счёте получилось так, что люди — снова — почти сразу стали использовать Flexbox для создания грид-макетов. Многие фреймворки предлагают CSS-класс `.container`, который применяет Flexbox к элементу, а затем работают с классами колонок, чтобы получить горизонтальную сетку. Вертикальные сетки работают через вложенные флексбоксы. Так что Flexbox — это инструмент вёрстки, но нам всё ещё нужно было сделать ещё один-два шага вперёд, чтобы получить полноценные сетки.

С выходом CSS Grid разработчики наконец получили то, что они импровизировали с самого зарождения Всемирной паутины — рабочий инструмент для грид-вёрстки. Наконец-то мы смогли строить сетки так, как это уже давно было реализовано во многих других языках и фреймворках. Для справки: самое раннее упоминание `GridPane` из JavaFX, которое я смог найти в сети, датируется 2003 годом — почти за 15 лет до того, как CSS Grid стал готов к продакшену.

И на этом наше небольшое путешествие сквозь десятилетия закончено. Сегодня, благодаря прекращению поддержки Internet Explorer 11 от Microsoft в 2022 году, все значимые браузеры полностью поддерживают CSS Grid. В результате мы можем наконец использовать его, чтобы воплотить в жизнь фантастические дизайны, которые придумывают UX-специалисты, и применять сетки вместо того, чтобы думать, как заставить что-то вести себя как сетка.

Однако есть один сценарий, для которого нам всё ещё приходится возвращаться к вложенным таблицам, плавающим элементам и вёрстке без Flexbox и CSS Grid — это шаблоны электронных писем. Конечно, и для этого есть решения, но это уже совсем другая история.

Книга также может быть полезна UX-специалистам с базовыми знаниями фронтенд-разработки, которые хотят освоить эффективный инструмент для более быстрого создания прототипов.
