JavaScript-зависимости, также доступны для всех основных операционных систем.

Для работы с разными версиями NodeJS рекомендуется либо настройка через Docker, либо Node Version Manager (NVM). Нам также потребуется современный браузер, поддерживающий CSS Grid и предлагающий инструменты для работы с сетками и отладчик гридов. Наличие нескольких установленных браузеров помогает нам увидеть различия в инструментах разработки и привыкнуть к ним.

Если вы используете цифровую версию этой книги, мы советуем набирать код самостоятельно или брать его из GitHub-репозитория книги (ссылка доступна в следующем разделе). Это поможет вам избежать возможных ошибок, связанных с копированием и вставкой кода.

Используемые соглашения

В этой книге используется ряд текстовых соглашений.

Код в тексте: обозначает кодовые слова в тексте, имена таблиц базы данных, имена папок, имена файлов, расширения файлов, пути, фиктивные URL-адреса, вводимые пользователем данные и никнеймы в Twitter. Вот пример: «Общее количество `fr` определяет размер каждого `fr`».

Блок кода оформляется следующим образом:


.container {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-rows: 1fr 4fr 1fr;
}
